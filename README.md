# JVS Exact Brochure Website

This version is intentionally built to look exactly like the supplied JVS brochure image.

## Files

- `index.html`
- `assets/jvs-brochure.jpg`

## Run

Open `index.html` in a browser.

Or:

```bash
python -m http.server 5500
```

Open `http://localhost:5500`.

## GitHub Pages

1. Create/open your `jvs-website` repository.
2. Upload `index.html` and the `assets` folder.
3. Commit to `main`.
4. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. Save.

## Important

The brochure image is used as the visual layer to preserve the exact layout, typography, spacing, glow effects, images and branding from the supplied reference. Transparent HTML hotspots provide navigation/accessibility without changing the appearance.
